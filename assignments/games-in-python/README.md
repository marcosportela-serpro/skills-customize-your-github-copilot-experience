
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construir o clássico jogo da Forca para praticar manipulação de strings, estruturas de repetição, condicionais e interação com o usuário em Python.

## 📝 Tarefas

### 🛠️ Preparação do Jogo e Seleção da Palavra

#### Descrição
Implemente a lógica inicial do jogo escolhendo uma palavra aleatória de uma lista predefinida e preparando o estado inicial para exibição ao jogador.

#### Requisitos
O programa concluído deve:

- Definir uma lista com palavras possíveis para o jogo.
- Selecionar uma palavra aleatoriamente a cada nova partida.
- Inicializar a visualização da palavra oculta no formato `_ _ _`.


### 🛠️ Lógica de Tentativas e Encerramento

#### Descrição
Desenvolva o fluxo principal do jogo para receber palpites de letras, atualizar o progresso, controlar erros e finalizar com mensagem adequada.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras digitados pelo usuário.
- Atualizar e exibir o progresso da palavra conforme os acertos.
- Rastrear e exibir a quantidade de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas se esgotarem.
- Exibir mensagem final de vitória ou derrota.
